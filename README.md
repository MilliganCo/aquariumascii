# AquariumASCII

## О проекте

`AquariumASCII` — интерактивный ASCII-аквариум на `pygame` с симуляцией рыб, еды, пузырьков, водорослей и системой ухода. Проект сочетает симуляцию поведения, текстовый визуальный стиль и сохранение состояния аквариума между запусками.

## Что реализовано

- мир аквариума с отдельной логикой симуляции;
- рыбы, корм, пузырьки и водоросли;
- boids-like поведение и пространственный хеш для объектов;
- ASCII-сетка и отдельный рендерер интерфейса;
- панель ухода;
- сохранение и загрузка состояния аквариума.

## Стек и структура

- Python
- `pygame`
- основные файлы: `app.py`, `config.py`, `save_system.py`, папки `sim/` и `ui/`

## Запуск

```bash
python app.py
```

## Статус

Готовый симуляционный прототип. Проект уже самодостаточен как маленькое интерактивное приложение с живым состоянием мира.
